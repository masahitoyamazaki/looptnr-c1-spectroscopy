# 3点 unsigned 較正のチェック (2026-11-25, paper 1b)

問い: Sec. V の signed (π twist) 読み出しの代わりに、μ=0, ±μ0 の 3 本の full-length run を unsigned の
g_d^2(12)（r_d=2^{2-K} 固定, |X|≤0.02）で読み、放物線 (g_seed+ρμ)^2 を通せば μ* は決まったか。既存データのみで検証。

## ファイル
- `three_point.py` — 全解析（約 10 s）。入力: `Otsuki/sixvertex/data/sixvertex_sg_xi_predict.csv`（B9, cut=0.02, rate=fixed）,
  `seed_refit_20261112/refit_b9_table.csv`（全スキャンの大域フィット, 2026-11-25 修正版）, `twist_campaign_summary_20261119/campaign_summary.csv`。
- `three_point_pairs.csv` — 全スキャン中の厳密な対称ペア ±μ0（全 11 ケースで存在; 49 組）ごとの μ*_3, 相対誤差, 第2極小, 遅延予測, n_end, n_e。
- `signed_compare.csv` — signed one-shot（campaign / tab:signed）の μ_pred を同じ放物線で評価したもの。
- `run_length.csv` — 3 本の unsigned run の RG ステップ数 (n_end の和) と 2·n_cal, 7·n_cal の比。
- `three_point_mc.csv` — ノイズ MC（σ = 全スキャン放物線まわりの ln g2 の rms, 400 サンプル, μ0/|μ*| = 0.1–20）。
- `three_point_summary.txt` — 上記の表示用まとめ。

## 方法
- 3点フィット: ln g2 = 2 ln|ρ(μ−m)| を 3 点で最小二乗（2 パラメータ, 自由度 1）。m について sinh グリッドで profile し、全局所極小を精密化（大域解）。
  第2極小（もう一方の符号分枝: m が [−μ0, μ0] の内か外か）も記録し、コスト差 ΔC/σ² で分枝の判別力を評価。
  参考として g2 の 3 点厳密補間二次式の頂点（B²=4AC 制約なし）も出力（vertex_rel_err）。概して ln-LSQ より悪い。
- 遅延: F = g2(0)/[ρ(μ*_3−μ*)]² （全スキャン放物線）, delay = ln F/ln 2^{2−K}。不規則成分の床として、その (K,χ) で
  実際に達成された最大遅延（スキャン, signed one-shot, refined のいずれか）で頭打ち（d_cap）。signed の μ_pred も同じ扱い。
- 注意: 3 点は全スキャンフィットに含まれる同じ run なので、データでの相対誤差は in-sample（やや有利）。MC が out-of-sample の目安。

## 結果の要点
- K ≤ 1.25 と K=1.5, χ=40: μ0/|μ*| ≈ 0.5–10 なら μ*_3 の誤差は ≲1–2%（データ; K=1.25 χ32 の 1 組のみ 4.5%）, MC でも p84 ≲ 1–6%。
  signed one-shot（誤差 1–10%, n_cal 以降の注入 f_cal 分だけ系統的に小さい）と同等以上。遅延も達成済み最大値に届く。
- 失敗領域: (i) μ0 ≪ |μ*|（K=1.5, χ=32 で μ0/|μ*| ≤ 0.22 → 12–330% の誤差, 符号反転も）;
  (ii) μ0 ≫ |μ*| かつ σ 大（K=1.5 χ24/32, K=1.75: μ0/|μ*|=10–20 で符号誤り 9–39%）; (iii) K=1.75, χ=32 (σ=0.61) はどの μ0 でも MC の中央値誤差 ≥ 11%（p84 ≥ 29%）。
  判別条件の目安: 小 μ0 側 δμ*/μ* ~ σ|μ*|/(2√2 μ0), 大 μ0 側は ±μ0 の差 4|μ*|/μ0 が √2σ に埋もれると符号が決まらない。
- コスト: 3 本 × n_end = 67–206 RG ステップ。signed の 7 本 × n_cal（論文の手順）の 0.6–0.9 倍、最小 2 本 × n_cal の 2.1–3.2 倍。
  1 本あたり n_end(μ=0)/n_cal = 1.5–2.1。最大の差は μ0 を μ* を知らずに選ぶ必要がある点（μ* は 1.5e-6–1.2e-4, 符号も χ 依存）。
